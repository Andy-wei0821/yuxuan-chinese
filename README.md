# 语萱的语文专属提升

深圳初三（2027 中考）语文练习单页站点，手机优先。

## 页面内容

| 模块 | 说明 |
|---|---|
| 篇目总览 | 75 篇古诗文（36 篇文言文 + 39 首必背古诗词），按册别与文言/诗词筛选 |
| 精读 · 朗读 | 逐句朗读（可换音色、调语速、按标点做句读停顿）、意境水墨插画 |
| 默写自测 | 232 道挖空题，逐字判分、错字自动进错字本 |
| 讲读 · 点睛 | 每篇 5 块讲解（题解/主旨/写法/名句/中考怎么考），可整篇听讲解 |
| 答题公式 | 7 个中考答题公式卡（问法→步骤→采分点） |
| 阅读专练 | 记叙/非连续/说明/议论四文体 15 题，每题带名师点拨与采分点自评 |
| 真题实战 | 2023–2025 深圳中考真题三卷（题目+答案+逐题讲析+作文审题） |
| 实词擂台 | 40 题题库，每轮随机抽 10 题，选项顺序打乱 |
| 学情诊断 | 按本机练习记录自动生成薄弱点报告与行动步骤 |

## 技术说明

- 单文件 HTML，无外部依赖、无 CDN，断网可用（朗读需系统语音）
- 所有插画为内联 SVG 水墨图，按每篇诗文真实意象生成
- 练习进度保存在浏览器 localStorage，不上传任何数据
- 建议在手机 Chrome / Safari 或电脑 Edge 打开

## 隐私提示

页面含家长寄语与孩子姓名。GitHub Pages 为公开站点，搜索引擎可能收录；介意的话请在仓库设置中关闭 Pages，或将站点设为不公开。
