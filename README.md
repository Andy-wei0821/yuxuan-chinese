## 朗读技术方案（为什么微信里也能出声）

微信内置浏览器（Android X5 内核）虽然**暴露**了 `window.speechSynthesis`，
但 `getVoices()` 永远返回空数组、`speak()` 会**静默失败**（无报错、无日志），
靠特性检测无法识别，属于典型的"伪兼容"。

因此本项目**不使用**系统 TTS 作为主朗读通道，改为：

- 离线预生成 **1004 段神经语音 MP3**（2 个音色 × 1004 段）
  - `xiaoxiao` — 晓晓 · 女声 · 新闻播报腔（温暖清晰）
  - `yunyang` — 云扬 · 男声 · 新闻播报腔（浑厚稳重）
  - 由 Microsoft Edge 神经 TTS 合成，24kHz / 48kbps 单声道
- 页面按**句**懒加载：只下载当前朗读的那一句（约 23KB），手机流量友好
- 播放走原生 `<audio>`，X5 不限制媒体播放，微信 / QQ / 应用内浏览器均可正常出声
- 单句失败自动回退系统 TTS，不会"点了没反应"

### 目录结构

```
index.html              单文件页面（含全部样式、脚本、插画、数据）
audio/xiaoxiao/*.mp3    晓晓女声，1004 段
audio/yunyang/*.mp3     云扬男声，1004 段
```

音频 id 规则：正文 `<篇目id>_r<句序号>`，讲读 `<篇目id>_j<板块序号>`，
与页面内 `AUDIO_MAP` 一一对应。

## 手机端使用建议

1. **必须用网址打开**（不要下载成 HTML 再本地打开）。`file://` 协议下浏览器会拦截同目录 MP3 读取，朗读会退化成系统机械音。
2. 想让系统备用音也更好听，可在手机设置里把"文字转语音"引擎换成高质量包：
   - **小米 / Redmi**：设置 → 更多设置 → 语言和输入法 → 文字转语音输出 → 首选引擎 → 小米语音引擎 → 中文(普通话) → 选"高质量"
   - **荣耀 / Huawei**：设置 → 更多设置 → 语言和输入法 → 文字转语音输出 → 默认引擎 → 荣耀语音引擎 → 下载中文语音包（选"高质量/增强"）
3. 页面内「朗读设置」面板有实时诊断，会显示当前环境、预生成语音是否可用、系统备用音质量。

## 其它技术说明

- 页面单文件 HTML，无外部依赖、无 CDN，样式与脚本全部内联
- 所有插画为内联 SVG 水墨图，按每篇诗文真实意象生成
- 练习进度保存在浏览器 localStorage，不上传任何数据
- 文本中的通假字 / 异读字（27 处）只影响朗读发音，显示文本保持原样
